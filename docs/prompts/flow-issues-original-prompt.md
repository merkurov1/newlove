# Изначальный промт: обновление `/flow-issues/`

Обнови страницу и шаблон выпуска в разделе `/flow-issues/` (для RU и EN версий).

Контекст и роутинг:
- Логика применяется к компонентам выпусков в `/flow-issues/` и `/en/flow-issues/` (или соответствующему i18n-шаблону).

Требования к вёрстке и структуре:
1. Шапка и отступы:
   - Встрой сквозной основной хедер сайта.
   - Скорректируй верхний отступ (top padding/margin), чтобы контент корректно начинался под фиксированным хедером.

2. Динамический заголовок выпуска:
   - Формируй заголовок из массива `items` за период выпуска.
   - Формат (RU): `<Заголовок главного элемента> — Flow / поток — <Дата>`
   - Формат (EN): `<Main item title> — Flow — <Date>`

3. Обновленный блок метрик в шапке (3 карточки):
   - Карточка 1: "Опубликовано" / "Published" — количество элементов (`items.length`) за период.
   - Карточка 2: "Дней работы потока" / "Flow active days" — количество дней от старта проекта Flow до даты выпуска.
   - Карточка 3: "О чем выпуск" / "Summary" — короткая фраза-саммари в несколько слов (вместо медианы времени), строго вписывающаяся в сетку верстки.

4. Авторская колонка Пьеро (ИИ-анализ):
   - Добавь перед списком материалов вводный блок авторской колонки (2–3 коротких абзаца).
   - Текст генерируется на основе ИИ-анализа массива `items` за период выпуска (ключевой смысл и контекст).
   - Поддерживай двуязычность (создание версии текста на русском и английском).
   - Тон: лаконичный, точный, философско-технологичный.

5. Лента материалов выпуска:
   - Рендери все `items` за указанный период.
   - Каждый элемент выводит свой собственный заголовок и контент-блок на соответствующем языке.

Сделай чистый рефакторинг компонентов и шаблонов `/flow-issues/`, сохраняя адаптивность и общий дизайн-код сайта.
