## 6. Ограничения и статус доступа

- **РГБ** — записи доступны, поиск изоизданий выполнен через `search.rsl.ru` с фильтром `cols=izo`. Для ряда поздних плакатов (1963–1972) записей в изо-каталоге не найдено; это не доказывает отсутствия плаката, а лишь ограничивает каталожное подтверждение.
- **НЭБ** — страница коллекции при проверке вернула заглушку «Отключите VPN — НЭБ». Источник указан как точка входа, но конкретные записи по нашим предметам через НЭБ не подтверждены.
- **Музей кино** — онлайн-выборка фонда не содержит наших конкретных названий; страница фонда использована для контекста и как контакт для дальнейшего обращения.
- **Манеж** — страница выставки доступна, но не является каталогом наших листов; использована для исторического контекста.
- **Reklamafilm.com** — прямой запрос к `poster_history` и `decades` из среды завершился таймаутом; сведения о Хомове и «Неподдающихся» проверены по поисковой выдержке и сопоставлены с записью РГБ.
- **Gamborg Gallery** — коммерческая галерея; используется как вторичный источник для размеров и атрибуции малоформатных вариантов Краснопевцева, не как замена музейному каталогу.
- **Wikipedia / Mosfilm / DEFA / NFA** — фильмографические данные; для атрибуции плакатов не используются, только для года фильма, режиссёра и производственной студии.
